# 柴柴出走中 SHIBA DAYS

線上試玩：https://ben771024.github.io/mini-games/

GitHub Pages 使用 `main` 分支根目錄發布；HTML、CSS 與 JavaScript 無需建置。

單關卡 HTML5 / Canvas 像素橫向卷軸遊戲原型。直接用瀏覽器開啟 `index.html` 即可遊玩；遊戲本身不需安裝、建置或網路。Google 字型在離線時會自動使用系統字型。

## 開始遊玩

選擇黑柴桂桂或赤柴 Miso，按「散步出發」。沿著日和商店街向右前進，到達柴柴小屋即可過關。收集金幣、跳上遮雨棚、避開道路缺口，揮掌擊退貓咪和壞人。碰到敵人或掉進缺口會損失一顆愛心，三顆耗盡後可以重玩。

- 左右：方向鍵 ← / → 或 A / D
- 跳躍：空白鍵、↑ 或 W
- 手掌攻擊：J 或 X，朝面向方向攻擊
- 暫停：P / Esc 或工具列按鈕
- 手機：下方四個觸控按鈕，可同時按住移動並點按跳躍或攻擊。建議橫向遊玩。

桂桂體型較小、速度較快、跳得較高；Miso 體型較大、揮掌距離較遠。兩隻都能完成相同關卡。敵人也可從上方踩踏擊退。

## 區域網路手機試玩

電腦安裝 Node.js 時，在此資料夾執行 `node server.cjs`，電腦開啟 `http://localhost:4173`。手機連接同一個 Wi-Fi，開啟 `http://電腦區域網路IP:4173`；首次使用需允許系統防火牆的私人網路連線。按 Ctrl+C 關閉伺服器。

## 檔案

- `index.html`：角色選擇、遊戲介面與操作說明
- `style.css`：響應式版面及觸控介面
- `responsive.css`：手機選角高度與全螢幕版面調整
- `game.js`：原創程式繪製像素角色、街景、物理、碰撞及遊戲狀態
- `server.cjs`：無外部套件的本機靜態伺服器
- `verify.cjs`：遊戲流程與關卡可達性的無畫面驗證

這是玩法與美術確認用原型，目前不包含存檔或多關卡。資料夾內參考圖片僅供視覺方向參照，遊戲角色與場景皆由程式重新繪製。
